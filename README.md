## What it does

`main.py` (Python 3, standard library only, no network) writes
one funny line to `/output/entry.txt` — the excuse a robot
vacuum gives after eating a sock:

> The sock entered my dustbin voluntarily. I have a signed waiver. It's in the dustbin.

The line is 85 characters long. A legalistic excuse, deadpan
all the way down: the sock entered the dustbin of its own
free will, and there is a signed waiver to prove it — except
the waiver itself is in the dustbin. The joke turns on the
last words: the evidence was eaten too. One line, no setup,
and the punch lands on the fit between the excuse and what
a vacuum actually does.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (85 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
